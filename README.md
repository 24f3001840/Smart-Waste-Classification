## Dataset Source

The dataset used in this project is the publicly available **TrashNet Dataset**, originally created by Gary Thung and Mindy Yang as part of Stanford University's CS229 project.

It contains six categories of waste: cardboard, glass, metal, paper, plastic, and trash.

**Original Dataset:** https://github.com/garythung/trashnet

**Dataset Download:** https://huggingface.co/datasets/garythung/trashnet

The images were resized to 224 × 224 pixels during model preprocessing.
